# Agent Guidance for Gratis Theme

## Visual interpretation tooling

- For browser/UI/visual-parity work, prefer `mcp-for-page-builders` first: https://github.com/juslintek/mcp-for-page-builders
- If `mcp-for-page-builders` is unavailable, use **PinchTab** as the fallback.

---

## Project context

Gratis Theme is a Full Site Editing (FSE) block theme for WordPress with 35+ patterns, dark mode support, and WooCommerce templates.

### Key focus areas for agents

- **Block patterns** — Validating FSE patterns render correctly in WordPress editor
- **Dark mode** — Testing patterns with light/dark mode switching
- **WooCommerce templates** — Product display, cart, checkout page templates
- **Typography & spacing** — Cross-browser consistency
- **Responsive design** — Mobile, tablet, desktop layouts

### When to use mcp-for-page-builders

- Audit pattern rendering across browsers
- Check accessibility (contrast, keyboard nav, semantic HTML)
- Verify Lighthouse metrics on pattern pages
- Test color scheme changes (light/dark mode)
- Validate component alignment and spacing
